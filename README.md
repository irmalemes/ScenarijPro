
# ScenarijPro

ScenarijPro is an academic web application project developed using **JavaScript, Node.js, MySQL, and Docker**.

The project focuses on web application development, backend functionality, relational database integration, and organizing a containerized development environment.

## Technologies Used

- **Programming Language:** JavaScript
- **Backend:** Node.js
- **Database:** MySQL
- **Tools:** Docker, Git

## Project Highlights

- Web application development
- Backend and database integration
- Relational data management
- Docker-based development environment

## Academic Project

Developed as part of university coursework at the **Faculty of Electrical Engineering, University of Sarajevo**.
